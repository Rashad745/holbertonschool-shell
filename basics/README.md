# Shell Scripting Learning Tasks

## Overview
This repository contains tasks and exercises designed to help you learn **Linux shell commands** and **shell scripting**. By completing these tasks, you will gain practical experience in navigating the Linux filesystem, managing files and directories, and automating tasks using the shell.

---

## Prerequisites
Before starting, ensure you have:
- Access to a **Linux environment** (Ubuntu recommended).  
- Basic knowledge of terminal commands.  
- A text editor like **VS Code** or **nano** installed.
